# Calamus 接续摘要

更新：2026-11-16。继续开发时先读本文件、git status 和开发计划未完成项；详细历史按需查 PROGRESS.md。

## 工作约定

- pnpm monorepo：packages/core 为 TypeScript Canvas SDK，apps/web 为 React/Vite/Tailwind 画板。
- 每轮完成一个明确增量，更新 docs 完成勾选并提交本地 commit；不默认推送、部署或发布 npm。
- 实现完成与浏览器、真实设备验收分开记录，不能因单测通过勾选设备验收。
- 不覆盖用户已有作品；浏览器验收使用独立作品，结束恢复名称、主题、窗口尺寸和原作品。

## 已有能力

- 核心：平滑/压感笔画、整笔擦除、撤销重做、JSON/PNG/SVG、回放、高 DPI；活动路径/几何/栅格缓存及诊断页。
- 网站：自动保存、多作品管理/恢复、缩略图、主题、缩放平移、Stroke lab、键盘 JSON 备份。
- 最近：作品名称搜索、自然名称/最近修改排序、窄屏长名称卡片；排序偏好接入已有本地偏好存储。
- 回放可见采样边界改为二分查找；语义与大笔画读取复杂度回归通过，实际帧耗时未验收。
- 最近已完成排序持久化与刷新验收、异常存储读写回归；最新提交以 git log 为准。

## 当前验证与限制

- 106 项测试通过；作品搜索、排序及刷新恢复已在应用内浏览器验证。存储异常通过模拟对象回归，禁用存储 UI 仍待验收。
- 320×740 浅色长名称、1440×900 深色作品库已验收，不代表完整站点/真实手机验收。
- 缓存诊断微基准不等同于实际输入延迟或 GPU 完成耗时；默认上下文像素读回存在已记录差异。
- Worker flood fill、笔画选取/移动、形状、图层、局部擦除、批量备份未实现。

## 剩余主线

1. 完整网站多尺寸/主题/弹窗交互、真实触屏和笔压、跨浏览器验证。
2. 长笔画真实交互性能/内存、缓存与回放/导出回归，后台诊断取消验收。
3. 发布准备：包名/scope/身份、版本、作者与许可证、展示素材、CI 浏览器流程。
4. 推送/部署/npm 发布按明确任务执行；当前线上站点不代表最新本地代码。

## 常用检查

- pnpm test：核心、Web 和原生示例测试。
- pnpm --filter @calamus/web build：Web 类型检查与构建。
- pnpm check:package：真实 tarball 独立安装与消费验证。
- pnpm release:check：发布准备检查，尚有发布元数据缺项时非零属预期。
