# Calamus 开发进度

## 已完成的模块

- 核心实例与输入管理，包括采样、取消、销毁和尺寸适配。
- 自适应采样平滑、压感过滤、速度笔宽和可选稳定器。
- 可变宽几何、整笔填充和已提交笔画缓存。
- DPR 变化监听。
- SDK 历史管理，提供 undo、redo、clear 和状态通知。
- Playground 接入 SDK 历史，保留画笔配置与 PNG 导出。

## 本轮检查

执行 pnpm dev，画两笔后检查以下流程。

1. 撤销后剩一笔，重做后恢复两笔。
2. 清空后画布为空，撤销清空恢复两笔。
3. 撤销一笔后重新绘制，重做按钮禁用。
4. 导出 PNG 包含当前画布中的笔迹。

自动化覆盖历史恢复、重做分支失效、查询副本隔离及销毁后的操作错误。
8 项测试与生产构建通过，浏览器手工检查尚未完成。

## 本轮完成 · JSON 文档导入导出

- SDK 提供 exportJSON、loadJSON 和 parseDocument。
- 格式包含 schemaVersion、逻辑尺寸、笔刷及时间压力采样。
- 导入先校验再提交为一条历史操作，可撤销。
- 校验版本、尺寸、点数、有限数值、时间顺序及笔刷配置。
- Playground 提供 JSON 文件导入、导出和错误反馈。

检查流程为画两笔、导出 JSON、清空、导入、撤销导入。
当前导入要求画布尺寸匹配，颜色采用六位十六进制。
11 项测试和生产构建通过。浏览器文件下载与导入交互仍待实测。

## 本轮完成 · SVG 矢量导出

- SDK 新增 exportSVG 和 createSVG，页面新增 Export SVG 按钮。
- 每笔输出一个包含共享几何的 path，采用 nonzero 填充，背景透明。
- 增加 SVG 尺寸、路径数量、属性转义和空文档测试。
- 增加 JSON 导入失败后作品与历史保持完整的测试，并验证导入可撤销。
- 修复 JSON 对三位十六进制颜色的兼容性，支持 3、4、6、8 位格式。
- 14 项测试和生产构建通过。浏览器中 SVG 的视觉对照仍待完成。

检查方式为绘制不同粗细笔迹、导出 SVG、在浏览器打开并放大查看。
当前 JSON 仅接受十六进制颜色，命名颜色与其他 CSS 色值的往返兼容仍待完善。

## 本轮完成 · 基础笔画回放

- SDK 增加 play、pauseReplay、resumeReplay 和 stopReplay。
- 按笔画内相对时间逐步显示采样，笔画之间采用固定 120ms 间隔。
- 暂停后继续不会计入暂停等待时间。播放完毕或停止时恢复完整作品。
- 回放期间屏蔽绘制输入，历史操作和文档替换会结束回放。
- Playground 增加四个回放控制按钮。
- 16 项测试及生产构建通过。真实浏览器播放、暂停和恢复交互仍待验证。

检查方式为画两笔、播放、暂停、继续、停止，再导出并确认原始作品完整。
当前回放使用已有笔画数据，完整操作录制、真实笔间间隔及倍速控制仍待实现。

## 本轮完成 · 回放倍速和状态反馈

- play 支持 speed 参数，范围 0.25–4，界面提供 0.5×、1×、2×、4×。
- 新增 onReplayChange 状态通知，播放、暂停、恢复、停止及自然结束同步界面。
- 控制按钮随状态启用，播放期间锁定倍速选择。
- 引擎测试覆盖暂停后时间排除、2×自然结束、文档和历史保持、清空终止播放。
- 修正测试动画调度器，使多个帧任务按各自 ID 取消。
- 16 项测试及构建通过，浏览器回放体验仍待实测。

检查时选择 2× 播放，暂停等待后继续，确认不会跳过暂停期间的笔迹，结束后按钮恢复可播放状态。

## 本轮实现 · 本地自动保存与恢复

- IndexedDB 保存当前作品，按事务完成结果显示保存状态。
- 页面启动先读取并校验作品，完成恢复后开放交互。
- 写入串行执行，旧写入完成不会覆盖界面的最新保存状态。
- 恢复失败时保留存储内容并提示通过 JSON 导出保留编辑。
- 处理数据库阻塞和版本变更时的连接关闭。
- 现有 16 项核心测试、生产构建及最终类型检查通过。IndexedDB 刷新恢复尚未在真实浏览器验证。

检查步骤为画两笔、等待 Saved on this device、刷新、确认笔迹恢复，再清空并等待保存后刷新。
当前为单作品存储。跨标签并发编辑冲突处理仍待实现，最后完成的写入会成为下次恢复内容。

## 本轮实现 · 整笔橡皮擦

- SDK 增加 setTool，支持 pen 和 eraser。
- 命中已处理笔迹后隐藏整笔，抬起时统一提交为一次历史操作。
- 取消输入或切换工具会恢复本次尚未提交的擦除。
- 页面加入工具切换与操作说明。
- 18 项测试和生产构建通过。橡皮擦手势仍待浏览器实测。
- 当前固定擦除半径为 10 个文档单位，按输入采样点命中，极快拖动可能漏过采样间的笔迹，连续扫掠检测待完善。

检查步骤为画三笔、拖动擦掉两笔、撤销一次，确认两笔同时恢复。

## 本轮完成 · 橡皮擦连续扫掠

- 命中检测使用渲染多边形，检测相邻采样之间的完整擦除路径。
- 抬起事件也检测最后一段路径，避免快速拖动漏擦。
- 已命中的笔画跳过重复几何计算。
- 新增正反向快速穿越、平行远离和共线分离测试。
- 引擎级测试覆盖取消擦除、一次手势一次历史和撤销恢复。
- 20 项测试与生产构建通过。浏览器视觉和大量笔画擦除性能仍待验证。

检查步骤为绘制横线，选择 Eraser，快速从横线上方向下拖过，再撤销确认恢复。

## 本轮完成 · SDK PNG 导出

- SDK 提供异步 exportPNG，返回 Blob，支持透明背景或指定底色。
- 支持最高 4× 输出倍率，校验尺寸与像素总量，编码失败返回错误。
- Playground 改用 SDK 导出，增加透明背景与倍率设置，以及导出进行状态。
- 使用已提交作品导出，回放显示状态不会改变输出内容。
- 模拟 Canvas 测试覆盖输出倍率、格式和编码失败。20 项测试与构建通过，真实 PNG 编码和下载仍待浏览器验证。

检查方式为选透明背景与 2×，导出后检查图像尺寸应为 2000×1400，背景透明。

## 本轮完成 · 签名裁剪导出

- PNG 与 SVG 共用笔迹几何边界，支持 crop 与 padding。
- 界面增加 Crop to drawing 和留白设置。
- 计算边界包含笔宽，PNG 通过坐标变换保留作品位置关系，SVG 使用对应 viewBox。
- 空作品回退到完整画布尺寸。裁剪范围包含画布外已记录的笔迹。
- 22 项测试和生产构建通过，真实浏览器导出视觉待验证。

检查方式为在画布中心签名，勾选裁剪和透明背景，分别导出 PNG、SVG，确认四周只保留设定留白。
