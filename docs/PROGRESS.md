## 本轮检查

执行 pnpm dev，画两笔后检查以下流程。

1. 撤销后剩一笔，重做后恢复两笔。
2. 清空后画布为空，撤销清空恢复两笔。
3. 撤销一笔后重新绘制，重做按钮禁用。
4. 导出 PNG 包含当前画布中的笔迹。

自动化覆盖历史恢复、重做分支失效、查询副本隔离及销毁后的操作错误。
