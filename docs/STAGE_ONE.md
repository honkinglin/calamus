# 阶段一实施记录

## 已落地

- Calamus 实例接管输入、指针捕获、取消、resize 和渲染调度。
- Playground 通过 SDK 实例绘制，并保留已有历史和 PNG 导出。
- 每笔冻结笔刷参数，合并采样事件保留时间和压力。
- requestAnimationFrame 合并渲染请求。
- destroy 清理事件、观察器、动画和指针捕获。

## 待完成

- 稳定器短笔画与收笔体验优化。
- 可变宽轮廓及 StrokeSegment 数据模型。
- 活动层优化、DPR 独立变化检测及性能测量。
- 浏览器输入与真实触控笔验证。

## 验证

核心 TypeScript 和网站生产构建通过。阶段一仍在实施中。

## 本轮更新

- 实现按采样时间处理的自适应平滑、速度笔宽、压力过滤和半径稳定器，接入 Playground 控件。
- 修复其他指针取消事件误取消当前笔画，以及替换文档时活动笔画残留。
- 添加 5 项算法回归测试并纳入 CI。构建与测试通过。
- 浏览器手感仍未验证。较大的稳定半径会让短笔画显示为点，后续需要专门处理。

## 笔画几何更新

- 稳定半径随累计移动距离逐步增长，短划从起点就能产生位移。
- 输出可变宽多边形几何，圆形端点与连接区域采用一致绕向。
- 每笔使用一次 nonzero 填充，减少透明颜色在分段重叠处出现的接缝。
- 实时画布与 PNG 导出共用几何生成器。
- 7 项算法测试及生产构建通过。浏览器视觉、长笔画性能和实际压感设备仍待验证。
